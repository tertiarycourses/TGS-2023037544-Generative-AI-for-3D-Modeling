# Activity 2: Generate a Blender Gold-Sphere Scene with AI-Assisted Python

**Level:** Foundation
**Alignment:** K2 · K6 · A2

## Scenario

The team wants a repeatable proof-of-concept showing how natural-language intent can create named geometry and a material in Blender.

## Objective

Use the video workflow to request, inspect, run and verify a small Blender Python script.

## Output

A safe Blender script, a generated gold sphere scene and an execution evidence presentation.
