# Activity 9: Create a Neutral Studio Render and Visual QA Set

**Level:** Intermediate
**Alignment:** K3 · K5 · A3

## Scenario

The design team needs evidence renders that reveal form and surface quality rather than hiding defects with dramatic lighting.

## Objective

Use consistent cameras, lighting and colour settings to create comparable validation evidence.

## Output

A four-view neutral render set and a documented render configuration.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
