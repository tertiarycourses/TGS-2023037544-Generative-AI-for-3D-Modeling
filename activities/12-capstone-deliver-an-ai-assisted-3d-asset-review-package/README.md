# Activity 12: Capstone: Deliver an AI-Assisted 3D Asset Review Package

**Level:** Advanced
**Alignment:** K1–K6 · A1–A6

## Scenario

You are accountable for a complete product-asset handoff that will be reviewed by design, production and business stakeholders.

## Objective

Integrate brief, AI assistance, Blender refinement, validation, export and stakeholder recommendation.

## Output

A release-candidate Blender asset, target export, validation dashboard and decision-ready presentation.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
