# Activity 4: Develop and Select Three AI-Assisted Product Variants

**Level:** Intermediate
**Alignment:** K1 · K3 · A1 · A5

## Scenario

Stakeholders want options for the desktop product but need a defendable recommendation, not a gallery of arbitrary shapes.

## Objective

Generate meaningful design alternatives and select one using weighted acceptance criteria.

## Output

Three normalized Blender blockouts, a weighted decision matrix and a selected direction.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
