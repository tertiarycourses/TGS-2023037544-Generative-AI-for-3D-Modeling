# Activity 3: Iterate and Repair an AI-Generated Blender Script

**Level:** Foundation to Intermediate
**Alignment:** K2 · K6 · A2

## Scenario

A generated script fails after a Blender update and leaves partial objects in the scene.

## Objective

Diagnose a controlled script failure and use evidence-driven AI feedback to repair it safely.

## Output

A repaired rerunnable script, an error log and a before/after diagnosis.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
