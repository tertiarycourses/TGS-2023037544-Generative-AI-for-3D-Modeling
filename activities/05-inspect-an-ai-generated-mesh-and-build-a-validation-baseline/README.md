# Activity 5: Inspect an AI-Generated Mesh and Build a Validation Baseline

**Level:** Intermediate
**Alignment:** K4 · K5 · A3

## Scenario

An external AI mesh arrives with no quality record and must be assessed before refinement.

## Objective

Measure geometry, transforms, topology and evidence before making repairs.

## Output

A frozen baseline Blender file, defect register and validation dashboard.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
