# Activity 11: Prepare and Verify a 3D-Printable STL

**Level:** Advanced
**Alignment:** K4 · K5 · A4 · A6

## Scenario

The product concept must be delivered as a small physical prototype for ergonomic review.

## Objective

Convert a model into a watertight, correctly scaled print candidate with manufacturability evidence.

## Output

A millimetre-scale STL, printable-source Blender file and slicer-readiness checklist.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
