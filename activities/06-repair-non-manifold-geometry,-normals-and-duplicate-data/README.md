# Activity 6: Repair Non-Manifold Geometry, Normals and Duplicate Data

**Level:** Intermediate
**Alignment:** K4 · A2 · A3

## Scenario

The inspected model has a belly seam, flipped faces and doubled vertices that cause shading and export defects.

## Objective

Apply local, reversible repairs and prove that the original failing checks now pass.

## Output

A repaired manifold model with before/after evidence and regression results.
