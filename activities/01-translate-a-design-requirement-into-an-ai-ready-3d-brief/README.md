# Activity 1: Translate a Design Requirement into an AI-Ready 3D Brief

**Level:** Foundation
**Alignment:** K1 · K3 · A1

## Scenario

A retail innovation team needs a compact desktop product visual for stakeholder review and later prototyping.

## Objective

Create measurable geometry, appearance and delivery criteria before using AI.

## Output

A one-page model brief, prompt specification and acceptance scorecard.

## Files

- `INSTRUCTIONS.md` — detailed learner procedure
- `CHECKLIST.md` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
